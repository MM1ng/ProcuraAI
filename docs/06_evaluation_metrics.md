# Evaluation Metrics

## RAG Metrics

- Context precision: retrieved context relevance.
- Context recall: coverage of required evidence.
- Faithfulness: answer consistency with retrieved context.
- Answer relevance: answer usefulness for the user question.

## Business Metrics

- Budget compliance rate.
- Inventory validity rate.
- Constraint satisfaction rate.
- Purchase completion rate.
- Order creation success rate.

## System Metrics

- Average latency.
- Tool call success rate.
- Error rate.

The local implementation supports two evaluation paths:

- Mock evaluation rows with Ragas-compatible columns for deterministic demos.
- Agent evaluation rows generated by running the current procurement agent over
  `data/evaluation_questions.csv`, then recording the real answer, retrieved
  product contexts, selected plan status, model metadata, and trace ID.

Ragas and MLflow adapter files are included for future managed evaluation runs.
